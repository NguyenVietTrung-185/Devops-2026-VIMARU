# VIMARU News Portal - Deployment Notes

## Services

- Frontend: React + Vite
- Backend: Node.js + Express
- Auth Service: Node.js + Express

## Local ports

- Frontend: 3000
- Backend: 4000
- Auth Service: 5000

## DevOps milestones

- Milestone 0: Run without Docker
- Milestone 1: GitHub and Pull Request
- Milestone 2: Docker
- Milestone 3: Deploy on Windows
- Milestone 4: Deploy on Linux
- Milestone 5: Deploy online
